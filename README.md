 📅 Full-Stack Booking System

A full-stack booking system built with **React** and **Node.js** that allows users to book appointments through a calendar-style interface, while admins can manage and view all bookings.

This project was created as a **portfolio project** to demonstrate real-world full-stack development skills, including frontend, backend, database, and deployment readiness.



 🚀 Features

 User Features
- Book appointments by selecting a date and available time slot
- Calendar-style time slot selection
- Automatically disables already-booked time slots
- Real-time UI updates after booking
- Responsive and modern user interface

 Admin Features
- Secure admin login
- Admin dashboard to view all bookings
- Separate admin route (`/admin`)

 Technical Features
- RESTful API built with Express
- Persistent storage using SQLite
- Client-side routing with React Router
- CORS handling between frontend and backend
- Error handling and form validation

---

 🛠 Tech Stack

 Frontend
- React
- React Router
- CSS (custom styling and animations)

 Backend
- Node.js
- Express
- SQLite
- REST API
